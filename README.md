# FutsalMatch — Android Studio (Kotlin)

Aplikasi matchmaking tim futsal komunitas dengan Room Database, ViewBinding, dan Material 3.

## Cara Menjalankan di Android Studio
1. Ekstrak file `FutsalMatchApp.zip`.
2. Buka Android Studio -> **File -> Open** -> pilih folder `FutsalMatchApp`.
3. Pastikan koneksi internet aktif, lalu klik **Sync Project with Gradle Files**.
4. Pastikan Gradle JDK di **Settings -> Build, Execution, Deployment -> Build Tools -> Gradle** memakai **JDK 17** atau **Embedded JDK (jbr-17 / jbr-21)**.
5. Jalankan di Emulator / HP Android (minSdk 24 / Android 7.0+).
